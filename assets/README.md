# Visual Assets

This directory contains visual assets for the repository.

## Social Preview

**`social-preview.png`** — GitHub social preview image (1280x640px)

- Used when repository is shared on social media, Slack, LinkedIn
- Upload to GitHub Settings → Social preview

## Structure Diagrams

**`portfolio-structure.png`** — Repository structure visual

- Clean, professional diagram showing the organization of the portfolio
- Used in documentation and presentations

## How to Use

### GitHub Social Preview

1. Go to repository Settings
2. Scroll to "Social preview"
3. Upload `social-preview.png`

### In Documentation

Reference images using relative paths:

```markdown
![Repository Structure](assets/portfolio-structure.png)
```

---

**Note**: The actual image files are generated and saved in the `.gemini/antigravity/brain/` directory during development. Copy them here for use in the repository.

1. Copy images from artifacts to this directory
