# Tracker

This directory contains active work tracking.

## Structure

- **signals/** - Customer signal reviews and triage
- **scores/** - RICE/DRICE prioritization scores
- **incidents/** - Incident postmortems and action items

## Usage

As you work on product initiatives:

- Capture customer signals in `signals/`
- Score opportunities in `scores/`
- Document incidents in `incidents/`

These feed into decision-making and roadmap planning.
