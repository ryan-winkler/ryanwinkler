# Memory System

This directory stores learnings, decisions, preferences, and patterns that the AI learns over time.

## Structure

- `decisions/` - Product and technical decisions
- `preferences/` - Ryan's working preferences and style
- `domain_knowledge/` - Domain-specific learnings
- `patterns/` - Recurring patterns and solutions
- `learnings/` - Post-ship learnings and retrospectives

## How Memory Works

### Decisions

When a significant decision is made:

1. Capture the decision and rationale
2. Link to supporting evidence
3. Track outcomes over time
4. Update if decision changes

### Preferences

Learn and remember:

- Preferred frameworks for different problems
- Communication style and tone
- Review preferences (which agents, when)
- Tool and command usage patterns

### Domain Knowledge

Accumulate knowledge about:

- Customer segments and their needs
- Product domain and terminology
- Technical systems and architecture
- Market and competitive landscape

### Patterns

Identify and reuse:

- Common problem-solution pairs
- Effective workflows and sequences
- Risk patterns and mitigations
- Success patterns worth repeating

### Learnings

Capture insights from:

- Shipped features (what worked, what didn't)
- Incidents and postmortems
- Customer feedback and interviews
- Experiments and tests

## Memory Lifecycle

1. **Capture**: Record new information in the flow of work
2. **Structure**: Organize and link related memories
3. **Surface**: Bring up relevant memories at the right time
4. **Update**: Refine based on new information
5. **Archive**: Move outdated memories to archive

## Privacy and Scope

- Memory is workspace-specific
- No personal or sensitive data
- Focus on work patterns and product knowledge
- Can be cleared or reset at any time
